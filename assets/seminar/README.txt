이 폴더에는 세미나 자료 PDF 파일을 넣습니다.

lecture.html 하단 <script> 안의 seminars 배열에 아래 형태로
항목을 추가하면 세미나 목록에 제목/강사/일시/장소가 표시됩니다.

  { title: "세미나 제목", date: "2026-10-06 (화) 16:00",
    location: "가천대학교 공학관 401호", speaker: "홍길동 교수 (OO대학교)",
    file: "assets/seminar/파일명.pdf" }

file 경로에 적은 이름 그대로 이 폴더에 PDF를 넣으면 제목이
자동으로 다운로드 링크가 되고, 아직 파일이 없으면 "파일없음"으로
표시됩니다. 세미나가 아직 없을 때는 배열을 비워두면 됩니다.

※ 반드시 실제 웹서버(http://...)로 열어야 파일 존재 확인이
   동작합니다. lecture.html을 더블클릭해서 file://로 열면
   파일이 있어도 "파일없음"으로만 표시됩니다.
